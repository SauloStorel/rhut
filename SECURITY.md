# Segurança

Se você encontrar uma vulnerabilidade, não abra uma issue pública. Use o botão **Report a vulnerability** na aba [Security](https://github.com/SauloStorel/rhut/security) do repositório, que manda o relato de forma privada.

Conte o que encontrou, como reproduzir e qual o impacto. A resposta vem assim que possível.
